# LM Admin Tools

Builders for the paperwork that comes with field work: trips, per diem, travel and vacation requests, trip reports, RMAs, travel-date bonus sheets, weekly summaries and expense tracking. Each builder gives you a subject line and a formatted body to paste into email, or a PDF / .xlsx to attach.

## First time: set up your profile

Open **Your profile** and fill it in once. Every builder pulls from it.

| Field | Used by |
|---|---|
| Name | Every builder |
| Manager | Travel Request, Vacation Request |
| Address | Per Diem Calculator |
| Home airport | Find flights in Travel Request |
| Preferred airlines | Filters Find flights (blank = all) |
| Preferred hotel brands | Filters Find hotels (blank = all) |
| PTO days per year | Vacation Request tracking, resets January 1 |

## Trips

Start in **My Trips → New trip**. Enter only what doesn't change: customer, EPCN#, reason, dates, destination and any other Evertz staff.

**Join a trip** and everything you build is saved to that trip, so the Per Diem, Travel Request, Trip Report and Travel Dates for one job stay together. Work done outside a trip is kept separately.

## The builders

- **Travel Request Builder**: job details, a day-by-day agenda, flights out and back, extra stops for multi-city, and logistics. **Find flights** opens a flight search pop-up starting from your home airport; you can also attach a screenshot of the flight instead.
- **Per Diem Calculator**: per diem date ranges (one per trip; add more for separate days), currency, week ending. Attach flight PDFs or images and they're added as extra pages. Exports a PDF.
- **Trip Report Builder**: trip details plus sections you name, each with bullet points.
- **Vacation Request Builder**: date ranges, manager, and who to forward to if approved.
- **Travel Dates (Bonus)**: fills the month's travel days from your trips. **Import .xlsx** loads last month's submission so yearly totals carry over. Tradeshow (IBC, NAB) and HQ trips don't count toward the road bonus. Exports the full 12-month document.
- **RMA Request Template**: contact, shipping, request type and flags, then one row per part with serial number, firmware and problem. Send to the Evertz RMA Info, Service and CS Admin groups.
- **Weekly Summary**: last week and this week as bullets (Enter for a new bullet, indent to nest). Every week is saved; drag a saved card onto Last week or This week to reuse it.
- **Expense Tracking**: log each expense report, see unpaid ones, keep a checklist, and set a default monthly internet amount.

## Sending

Every builder has **Copy subject** plus **Copy formatted** (paste into Outlook with formatting) and **Copy as plain text**.

## Tips

- Your data follows you to any computer you log in from.
- Fill the profile first. Most "why is this blank" questions come from an empty profile field.
