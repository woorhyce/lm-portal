# LM Games

Four DreamCatcher training games in one place. Good for new operators, and for a quick refresher before a show. Your best score in each game follows you to any computer you log in from, and each card shows the team's top three.

## The games

- **Replay Op**: run two outputs, RED and BLUE, in a DreamCatcher VUE layout with a virtual RCP-10. The producer calls which output, camera and speed, sometimes both outputs on one play. Roll back on the output's timeline and hit play; it plays from there until you go back to live or the producer takes it. Mark IN and OUT only when you want a clip. Server faults pop up mid-show; pick the least disruptive fix.
- **DreamCatcher Replay Academy**: an arcade quiz in seven stages. Move your camera under the right answer before the gate arrives.
- **Input Breaker**: bounce the ball off your T-bar and break every input out of the multiview. Tally-lit inputs take more hits.
- **Million Frame Replay**: the operator quiz show. Use your lifelines, climb the ladder and walk off with as many frames as you dare.

## How to play

1. Open **LM Games** from the Tool Library.
2. Pick a game and press **Play**.
3. Use the **LM Games** button in the bottom-left corner to get back to the menu.

## Replay Op keys

Replay Op uses the real DreamCatcher keyboard shortcuts.

| Key | Does |
|---|---|
| Ctrl+F1 / Ctrl+F2 | Select output RED / BLUE (panel: A / B) |
| [ / ] | Mark IN, mark OUT |
| Shift+{ / Shift+} | Go to IN, go to OUT |
| \ | Create clip (next Clip View slot) |
| Backspace | Clear IN and OUT marks |
| Space or F1 | Play or pause, at the lever's speed |
| Enter | Queue the current clip |
| , / . | Jog back, jog forward (Shift+< / Shift+>: medium) |
| Ctrl+Shift+< / > | Decrease or increase play speed |
| Pause / Shift+Pause | Record (live, clears marks), Return (live, keeps marks) |
| M / Alt+M | Create event, create event at live |
| 1 to 0 | Go to slot 1 to 10 (selects the clip) |
| Enter | Queue the selected clip on the selected output |
| Del | Delete the selected clip |
| Shift+1 to 4 | Select bank 1 to 4 |
| Shift+: | Go to timecode |
| A | Alternate angles (camera A to D); panel: Shift+A to D, or click an input |
| Ctrl+Alt+R | Restart VUE (UI only) |
| Both Shift keys | Mark the logs |

Most Mac keyboards have no Pause key: use the panel's RECORD key instead.

## Clip View, Settings and Status

- Click a slot to select its clip, then click it again or press **Enter** to queue it on the selected output. Double-click queues straight away.
- **Settings** opens the real Operational settings pages. Some change the game: Zoom Levels set the zoom column beside each output, Show Thumbnails and Thumbnail to Show change Clip View, Absolute slot numbering, Create Clips for Events, Default Event Position, Fast Jog Multiplier, and Clear Marks on All Trains. Settings stay saved in your browser.
- **Status** has the General, Inputs, Outputs, Users, Network and Errors tabs. Faults show up on Errors with a Troubleshoot button.

## Sound

Replay Op has sound: crowd, snap, whistle and touchdown cheers, plus IFB chirps, panel clicks and alarms. Speaker Control in the VUE bottom bar mutes it, and Volume sets the level.

## Notes

- Each game's own controls are shown on its start screen.
- Sound can be toggled inside each game.
