LM-CORE-SC+DC-IO-MX8-12G-SDI

No LTC input with the LM-25GE

The 12-port SDI card takes LTC through a plate in the front PCIe slot. Fitting the LM-25GE there removes the LTC input, so this server must get its timing from PTP or NTP. Or switch to the 8-port card, which has LTC on the card.
